# Grammaire

A French grammar course from A1 to C2: 72 lessons with the theory behind each rule, 720 activities, unit tests, reviews and a verb lab.

It's an installable web app. Open the GitHub Pages address in Chrome on Android and choose **Install app**. It then works offline, and updates itself the next time it opens online after new files are uploaded here.

Progress is stored on the device, inside the app. Use **Progress → Download backup file** to keep a copy.

Fonts: Barlow, Barlow Semi Condensed and Newsreader, under the SIL Open Font License (see the OFL files).
